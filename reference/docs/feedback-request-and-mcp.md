# Featurebase MCP server (help.featurebase.app/articles/6144007)

Read-only tools:

- Feedback & Roadmaps: search/review posts, comments, votes, voters
- Help Desk: review conversations, tickets, customer history, categories, statuses, attributes
- Help Center: search/read articles, collections, help centers, redirect rules
- Users Directory: look up people, companies, customer data
- Reports & Surveys: query reporting data, analyze survey responses
- Updates & Configuration: review changelogs, audit logs, boards, statuses, tags, brands, teams, webhooks

Write/delete tools:

- Feedback & Roadmaps: create/update posts and comments; manage voters
- Help Desk: create/update conversations and tickets; send replies; manage participants, tags; redact content
- Help Center: create/edit/publish/delete articles, collections, redirect rules
- Updates: create/edit/publish/unpublish/delete changelogs
- Users Directory: create/update/block/unblock/delete contacts and companies
- Webhooks: create/update/remove/refresh signing secrets

No explicit "first-class" hierarchy is stated; all tool groups are presented as equally supported. This matches the resource/operation scope implemented in this package.
